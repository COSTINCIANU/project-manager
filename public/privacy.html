Politique de confidentialité

Dernière mise à jour : 7 juin 2026

Project Manager est une application de gestion de projets développée par COSTINCIANU Gheorghina dans le cadre d'une formation CDA (Concepteur Développeur d'Applications) niveau 6.

1. Données collectées

Nous collectons uniquement les données nécessaires au fonctionnement de l'application :

  • Adresse email et nom d'utilisateur
  • Données de projets et de tâches créées dans l'application
  • Fichiers liés via Google Drive (liens uniquement, pas de contenu)
  • Événements synchronisés avec Google Calendar

2. Utilisation des données Google

Project Manager utilise les APIs Google suivantes :

  • Google Drive API — accès en lecture seule pour sélectionner des fichiers à lier à vos tâches. Nous ne stockons pas le contenu de vos fichiers, uniquement les liens de partage.
  • Google Calendar API — création d'événements dans votre calendrier principal pour les tâches avec date d'échéance. Nous ne lisons pas vos événements existants.
  • Google OAuth — authentification sécurisée via votre compte Google.

3. Partage des données

Nous ne partageons, ne vendons ni ne louons vos données personnelles à des tiers. Les données Google sont utilisées uniquement dans le cadre des fonctionnalités décrites ci-dessus et conformément aux Règles d'utilisation des données utilisateur des services API Google .

4. Stockage des données

Vos données sont stockées sur des serveurs sécurisés hébergés par o2switch (France). Les tokens d'accès Google sont stockés temporairement dans votre navigateur (localStorage) et expirent automatiquement.

5. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès à vos données
  • Droit de rectification
  • Droit à l'effacement
  • Droit à la portabilité

Pour exercer vos droits, contactez-nous à : contact@costincianu.fr
