C'est quoi Docker ?
Docker permet de empaqueter toute ton application dans des conteneurs — comme des boîtes isolées qui contiennent tout ce qu'il faut pour faire tourner l'app.
Sans Docker :
"Ça marche sur mon PC mais pas sur le serveur !"

Avec Docker :
"Ça marche partout — même environnement garanti !"

Ce que ça implique pour ton projet
On créerait 3 conteneurs :
🐳 Conteneur 1 — React (frontend)
🐳 Conteneur 2 — Symfony (backend)
🐳 Conteneur 3 — MySQL (base de données)
Tous les 3 communiquent ensemble avec Docker Compose.

✅ Montre que tu maîtrises les outils professionnels
