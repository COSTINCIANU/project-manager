🟦 Les 4 cartes en haut (StatCard)
Ce sont les statistiques globales du dashboard. Elles se mettent à jour automatiquement quand tu coches des tâches :

Projets actifs → combien de projets sont "En cours"
Tâches totales → le nombre total de tâches
Complétion → le pourcentage de tâches terminées
Urgentes → les tâches non faites avec priorité "haute"


🟦 La carte Projets (à gauche)
Elle affiche la liste de tes projets avec pour chacun :

Un point coloré pour identifier le projet
Le nom du projet
Une barre de progression visuelle
Un badge de statut (En cours / Terminé / En attente)


🟦 La carte Tâches (à droite)
C'est la partie interactive principale :

Tu peux cocher une tâche → elle se barre et les stats se mettent à jour automatiquement
Tu vois le projet associé à chaque tâche
Un badge de priorité coloré (haute / moyenne / basse)
En bas un formulaire pour ajouter une nouvelle tâche
